# Civilization V — справочник

Веб-справочник по Civilization V. В нём можно искать и просматривать информацию о цивилизациях, юнитах, ресурсах, технологиях и зданиях.

## Возможности

- поиск по разделам справочника;
- подробные карточки с информацией об объектах игры;
- светлая и тёмная темы с сохранением выбора;
- адаптивный интерфейс для компьютеров и телефонов.

## Запуск локально

Требуется Node.js и npm.

```bash
npm ci
npm start
```

После запуска приложение будет доступно по адресу `http://localhost:3000`.

Для production-сборки:

```bash
npm run build
```
